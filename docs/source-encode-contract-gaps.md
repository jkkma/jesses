# Source encoding control-to-request audit

**Current user scope: CPU encoding only.** The explicit latest request removes all hardware video encoding, including NVENC, from Jesses. Legacy hardware job records remain readable but active hardware encoding requests must be rejected; packet copy/imported media remains supported. Vulkan processing, libplacebo Spline tone mapping, and GPU-assisted metrics/scoring are explicitly preserved. Historical NVIDIA receipts are evidence of past exploration, not a current capability or pending qualification.

Audit scope: the current Nmkoder fork at `~/repos/nmkoder`, `MainWindow.axaml:198–800`, its encode task builders and all four encode dialogs in `docs/nmkoder-dialog-inventory.md`. The complete 149-control extraction and codec-by-codec source tables are in `docs/nmkoder-ui-parity.md`; this document maps those controls to Jesses' current DTO/consumer and identifies the work required. Source line references below are relative to `~/repos/nmkoder/Nmkoder`. Jesses references are relative to this repository. Status describes the contract as inspected in this shared checkout; it is not a claim that every UI path has been tested.

**Classification:** Existing = typed operation exists and needs UI wiring/verification; Extension = source operation cannot be faithfully represented by the present contract; Conditional = existing contract can handle some source values but restricts others. Do not treat a disabled/guarded option or an approximation as completed parity. The latest user preference is paper-and-ink styling with the approved compact two-column/three-column layout.

## Audio, subtitle, metadata and track authority

Quick now derives whether video is processed from the checked tracks while
keeping the visible codec draft. With no checked video, its non-image request
omits video and inactive picture processing and uses `videoMode: drop`; no
checked tracks logs the source warning and returns to Track List. Focused
browser checks cover primary audio/subtitle and external-only audio requests.
The native held-FFmpeg test
`subtitle_only_and_external_only_selections_never_reintroduce_unchecked_primary_video`
rendered a
subtitle-only MKV and an external-audio-only output with an empty primary map;
both were probed with no unchecked video. Fixed-image implicit mapping is a
separate open edge described below.

The Quick Metadata grid now includes the previously missing `Output File`
Title/Lang row. Source initializes it from the current file, retains edits per
loaded file, trims both values on save, and emits explicit empty strings to
clear metadata when Apply is checked; Apply unchecked omits those overrides.
Implicit-image and normal Quick requests carry this mapping. Quick emits
explicit false flags for Metadata/Chapters `None`; batch ignores the entire
grid and resolves Current Input per source. Focused browser request tests cover
these states. One real-media test passed 12 normal copy/x264 and held
unchanged/edited metadata scenarios, including donor None, blank clears and
attachment tags (`target/test-artifacts/source-command-edit/metadata-real.log`);
other native routes and platforms remain separate.

Source batch now iterates the complete File List and derives video/no-video
conversion independently for each input while retaining the selected video
codec in the UI. Mocked UI cases cover 101 entries, mixed inputs, frozen
settings and Stop/retry. Native real-media tests passed 7/7 including 101
inputs, mixed outputs and cancellation during a live probe; see
`target/test-artifacts/source-command-edit/source-batch-final.log`.

Quality zero is codec-specific: the fork passes literal zero CRF to Direct
SVT/x264/x265 and AV1AN equivalents, and zero CQ to Direct/AV1AN AOM/VPX;
The hardware-only Quick lossless-tune branch is now excluded by user scope. The source UI sends CPU distinctions
without adding a lossless control, and mocked frontend coverage exercises all
12 selections. Native SVT zero validation and real Quick/AV1AN provider qualification passed;
explicit native lossless remains a distinct API. The single source SVT identity
now resolves the exact pinned HDR provider and preserves existing saved-job tool stamps.

Source trim permits mapped copied audio alongside encoded video; only copied
video is coerced to keyframe mode (`QuickConvert.cs:162–184`). The Direct source
adapter now freezes `sourceTrim:true` and accepts copied audio/ASS packets with
source-equivalent seek/preroll and one verified mux clock. Five real Linux gates
and the unchanged five-gate legacy API suite pass; the previously pending
browser request test now passes. See [copied-track trim proof](source-copied-trim.md).
AV1AN's copied input intermediate
remain separately open; copied subtitle packet support does not imply that all
conversion/burn boundary cases have been qualified.

### Numeric/type and value-mapping audit still requiring corrections

- **Settings:** Source auto-crop samples is integer 1–100 (default 10); keyframe interval is integer 1–120 seconds (default 10). UI clamps on change and backend validates. Zero-index is a display preference; verify all track/default-grid numbers follow source per-kind display numbering, while IPC always uses actual zero-based stream indexes. Output-directory invalid/missing restoration still needs actual native error-path coverage.
- **Sample Encodes:** Source CRFs are integers only. It discards unparsable/negative tokens, clamps to encoder range (0–51 for x264/x265/NVENC, 0–63 for VP9/SVT/AOM), deduplicates, sorts and takes at most 8; if none survive, it uses that encoder's three defaults. The UI parser now matches these rules; a focused request test covers negative, fractional, duplicate, out-of-range and all-invalid inputs. Samples are integer 1–8; seconds per sample integer 2–120; request values are clamped to those bounds. The source color/preset arrays and defaults are in `docs/nmkoder-native-ui-handoff.md`; all 27 software source formats now pass real backend verification; GPU hardware remains deferred.
- **Film Grain:** Denoise is integer 1–16/default 4, ISO integer 1–409600/default 400 and step 100. Stored values are validated; live request values are clamped to those bounds. Source Reset restores operation/source/table/preset/ISO/chroma/denoise/keep. Result and warning text now reflect the selected operation and source dimensions/duration; the estimate is explicitly approximate. Native long-running progress still needs end-to-end verification.
- **Metrics:** Subsample is a choice of integer 1–32 (default 1); verify selected numeric value serializes as a number, and each alignment/model enum reaches the intended backend transformation. VMAF/SSIM/PSNR selection is transactional; zero-metric behavior and source validation should be compared. Two selectors must re-guess both smallest/largest when either stored path disappears.
- **Deinterlace:** Mode and QTGMC preset are typed enum choices, not free text; QTGMC presets must cover Placebo through Very Fast, and auto/forced selection must preserve detection parity and bob/frame count. Shared resolver now applies this, with fixture and backend proofs; native Windows/provider-unavailable/cancel cases remain.
- **Cut:** Text is parsed as plain seconds or `HH:MM:SS[.mmm]`; copied start snaps at/before keyframe and end must exceed it within duration. Validate precision, near-end/post-snap cases and frame-rate-derived ±1-frame nudges. Fork treats an empty interval as null; shared-dialog owner is addressing this behavior.
- **Bitrate/OCR:** Stream IDs are source-scoped zero-based IPC values even when labels are one-based. OCR currently derives a Tesseract language from three-letter metadata or English fallback; compare fork Subtitle Edit language/templates and verify non-English datasets rather than silently claiming equivalence. Read-bitrate units, per-kind totals and final partial window require exact source comparison.
- **Lists and modes:** File size is decimal-string bytes; modified time is signed milliseconds and can be absent; preserve sort stability and unknown timestamps. Batch name `index` is source-width zero padded, `quality` aliases `crf`, and unsupported placeholders require source behavior validation. Track default selectors show per-kind ordinal indexes, not global stream IDs; the default-track menus now display per-kind ordinals and retain source-scoped IPC identities.

### Image-sequence frame-rate input

The fork's `Nmkoder/Data/MediaFile.cs:78–89` opens `Enter Frame Rate` with default `30` for each folder; a blank or closed prompt retains `30`. `Nmkoder/Data/Fraction.cs:54–72` parses an explicit `numerator/denominator` pair, while a decimal is converted to a float and rounded to an integer (`Nmkoder/Extensions/ExtensionMethods.cs:106–109`, .NET midpoint-to-even). Thus `24000/1001` remains exact and `23.976` becomes `24/1`. Jesses follows those conversions and validates a positive rate within the native 0.001–1000 fps contract; the validation explains otherwise-invalid input instead of submitting an invalid sequence job. Duplicate folder paths are identified by their original directory, preserving the first imported rate and avoiding a second materialization.

### Single-output default naming gap

The fork's `QuickConvertUi.InitFile` and AV1AN counterpart populate an extensionless `UiData.GetDefaultOutPath` stem. `UiData.GetOutPath` adds the chosen container only for execution; `QuickConvertUi.ValidatePath` / `Av1anUi.ValidatePath` then choose the first free `stem (n).ext` when the real target already exists. PNG/JPEG sequence exports use a directory-aware variant. Existing Jesses stores a full output filename in the field and, for regular sources, still suggests an encoder suffix (`_av1`, etc.). Sequence suggestions now use the original folder basename and preserve dots, but the general stem presentation, actual source-style `(n)` collision step and safe selection for already existing sequence outputs need a narrow native available-name resolver or an equivalent verified reservation. The existing batch preview resolver is request-specific; the UI must not guess filesystem state, overwrite the source, or silently claim parity. Backend no-clobber remains authoritative.
